## 📋 Acerca del repositorio

Este repositorio reúne el trabajo académico desarrollado durante la asignatura **Bases de la Programación Web**.

Su propósito es organizar y documentar los recursos de aprendizaje, códigos fuente, ejercicios prácticos, evidencias y proyectos realizados durante el desarrollo de la asignatura.

El contenido está organizado por semanas para facilitar la consulta, actualización y seguimiento de las actividades.

## 🎯 Objetivos

- Organizar las actividades y prácticas desarrolladas durante la asignatura.
- Aplicar los fundamentos de la programación y el desarrollo web.
- Documentar los ejercicios y proyectos realizados.
- Desarrollar habilidades en el uso de tecnologías y herramientas web.
- Utilizar Git y GitHub para el control de versiones.
- Mantener un historial de aprendizaje y evolución técnica.

## 🚀 Proyectos destacados

### 1. Hola Mundo API – ASP.NET Core Web API

API REST desarrollada con C# y ASP.NET Core Web API, que implementa un endpoint HTTP GET para devolver un mensaje de bienvenida en formato JSON.

**Características:**

- Desarrollo con .NET 10.
- Implementación mediante Minimal API.
- Endpoint `GET /api/hola`.
- Respuesta JSON.
- Pruebas con navegador y Postman.

📂 **Ubicación:** `semana-03/HolaMundoAPI-ASP.NET-Core/`

🔗 [Consultar proyecto HolaMundoAPI](semana-03/HolaMundoAPI-ASP.NET-Core/)

## 🔄 Control de versiones

Este repositorio utiliza Git y GitHub para administrar los cambios del código fuente y mantener un historial de las actividades desarrolladas.

Comandos principales:

```bash
# Consultar el estado del repositorio
git status

# Agregar los cambios
git add .

# Crear un commit
git commit -m "Descripción de los cambios"

# Publicar los cambios
git push origin Main

# Actualizar el repositorio local
git pull origin Main
```
